# Demo accounts

Every seeded account, generated from `src/OnCallApp.jsx` by script so it
cannot drift from what the app builds. Sign in with **either** the email or
the username. **Any password works** in this build — there is no real
authentication yet (see `requirements.md`).

Entering any address at an organization's domain reaches its sign-in screen,
whether or not that person is on the roster — the domain is what selects the
tenant.

Names and phone numbers are placeholder data.
