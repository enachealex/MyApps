Set up KidView on this device

Two steps, then it's ready to watch.

KidView for kids works on Android phones and tablets. Scan the code with the child's Android device.

  1. Install KidView

    Tap the button, then open the file when it has downloaded. Because KidView isn't from the Play Store, Chrome says the file "might be harmful" (it says that about every app from a website: tap Download anyway), Android asks once to allow installs from this browser, and Google Play Protect may ask you to confirm.

    Download KidView
  2. Connect it to your home

    When KidView is installed, come back to this page and tap:

    Open KidView

    KidView opens with your home's details filled in. Give the device a name and tap Connect.

Didn't open? Open KidView and type the server address and the family code .

Scan the setup code

Open the KidView dashboard at home and scan the code under Set up a kid's device with this phone's camera.
